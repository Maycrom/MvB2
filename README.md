# Monkeys VS Bloons 2
**The official sequel to the original Bloons TD Battles mod, now in BTD5!**
This is a massive passion project that I've been working on for the past few months. I've had to make a lot of very scuffed custom systems for this mod and it's honestly a miracle they work at all. Most of the custom assets fit in with the BTD5 artstyle, I will try my hardest to keep it this way as I keep updating the mod.

MvB2 attempts to bring Plants Vs Zombies style gameplay to Bloons TD5 with its own little twists.
Content wise, it is currently still a little bit lacking but there are a few maps and towers to mess around with. There are a lot of hardcoded things in this game that I cannot change, some of these don't really work with the mod. I've tried my best to mark broken/incompatible content.
