

FOREWORD

  Thank you for downloading MvB2!
  This mod pushes Bloons TD5 close to the limit of what can be achieved with modding in this game. (In a lot of aspects this game is very hardcoded...)
  To best experience this mod I recommend starting a new save file. You can do this through the following methods:
  
  METHOD 1
  Start BTD5 and click on the settings building in the main menu.
  Click on the "cloud" button, here you can delete your save data.
  
  METHOD 2 (Recommended)
  1. Head over to your steam library
  2. Right click Bloons TD5, hover over "Manage" and click on "Browse local files"
  3. Go back 3 folders until you end up in your Steam folder
  4. Head over to the "userdata" folder and sort the files inside by date modified (not required if you only have 1 folder in there)
  5. Go inside and look for a folder named "306020". Then follow this file path: local -> Data
  6. Make a copy of the "Docs" folder and put it somewhere safe (this is your save file!)
  7. Delete the "Docs" folder
  
  When you want your old save back just follow the steps again and place the copy of your "Docs" folder back in there.
  If you end up enjoying the mod I recommend backing up the save file for it aswell since I will be adding more content over time.

INSTALLATION

  Keep in mind this mod only works on the Steam version of the game, it also does not work on MacOS. 
  For Linux users, check the instructions below.

    Windows

    1. Install NKHook5 (https://github.com/NKHook/NKHook5)
    2. Head over to your steam library
    3. Right click Bloons TD5, hover over "Manage" and click on "Browse local files"
    4. Go into the MvB2 folder in this zip archive, take all of the files and drop them into the folder that opened during the last step.


    Linux

    1. Follow the windows installation steps
    2. Add WINEDLLOVERRIDES="wininet.dll=n,b" %command% to your Bloons TD5 launch options on steam with proton 10
    3. Should in theory work, I dont use linux myself but we have 2 confirmed cases of this working
